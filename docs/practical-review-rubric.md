# Practical work review before paid launch

The current practical gate grades three selected decisions from synthetic evidence. It does not verify tool execution or proctor identity. The worksheet is optional, saved locally and downloadable. A private submission/review workflow is now prepared in [practical-report-review.md](practical-report-review.md); it does not change the practical gate or credential eligibility and awaits deployment approval.

## Proposed human review

Use owned training resources and supplied artifacts only. A reviewer should reconstruct the learner's reasoning, not score writing length or fluent terminology.

| Criterion | 0: missing/unsupported | 1: partial | 2: reconstructable |
| --- | --- | --- | --- |
| Evidence | No source or invented facts | Sources listed, linkage unclear | Identifiers, source/time and decision linkage are explicit |
| Reasoning | Unsupported verdict | Some correct steps, major gap | Steps/calculations support the scoped conclusion |
| Limits | Overclaims identity, cause or full security | Some uncertainty stated | Observations, hypotheses and missing evidence are separated |
| Retest | No verification or breaks legitimate use | One-sided test only | Allowed/denied cases, expected result and rollback/stop condition |

Before using this rubric for credentials, agree an adjudication/appeal process, calibrate at least two reviewers on examples and validate learning prerequisites. The prepared feedback workflow uses 6/8 with no zero for report acceptance, **not for credential eligibility**. Invented evidence, testing outside permission, or secrets in a submission require correction before review; these are not automatic allegations against a learner.

## Platform work still required

- Activate the prepared private storage, explicit consent, existing administrator role, immutable history and resubmission workflow after approval.
- Define an operational appeal/retention process and calibrate reviewers before linking review to credentials.
- Actual controlled lab tasks with logs/artifacts, not an answer-choice proxy.

Until then describe the credential as Academy educational completion, not accredited or independently assessed professional competence.
