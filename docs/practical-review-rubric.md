# Practical work review before paid launch

The current practical gate grades three selected decisions from synthetic evidence. It does not verify tool execution, proctor identity or manually review the learner's report. The new worksheet is optional, saved locally and downloadable; it does not change that gate or credential eligibility.

## Proposed human review

Use owned training resources and supplied artifacts only. A reviewer should reconstruct the learner's reasoning, not score writing length or fluent terminology.

| Criterion | 0: missing/unsupported | 1: partial | 2: reconstructable |
| --- | --- | --- | --- |
| Evidence | No source or invented facts | Sources listed, linkage unclear | Identifiers, source/time and decision linkage are explicit |
| Reasoning | Unsupported verdict | Some correct steps, major gap | Steps/calculations support the scoped conclusion |
| Limits | Overclaims identity, cause or full security | Some uncertainty stated | Observations, hypotheses and missing evidence are separated |
| Retest | No verification or breaks legitimate use | One-sided test only | Allowed/denied cases, expected result and rollback/stop condition |

Before using this rubric for credentials, agree an adjudication/appeal process, calibrate at least two reviewers on examples and validate learning prerequisites. A suggested draft threshold is 6/8 with no zero, but **it is not an active platform rule**. Invented evidence, testing outside permission, or secrets in a submission require correction before review; these are not automatic allegations against a learner.

## Platform work still required

- Private report storage and explicit learner submission consent.
- Reviewer roles and an audited review history, resubmission and appeal.
- Actual controlled lab tasks with logs/artifacts, not an answer-choice proxy.
- Measured workload, ambiguity review and accessibility feedback from learners.

Until then describe the credential as Academy educational completion, not accredited or independently assessed professional competence.
